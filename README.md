# Weapon Challenger 2D

여러 무기와 약점 공격으로 4명의 보스를 공략해 점수를 획득하고, 웹 랭킹과 개인 기록을 확인하는 2D 액션 웹게임입니다.

## 프로젝트 소개

브라우저에서 Unity WebGL 게임을 플레이할 수 있습니다. 각 스테이지에는 서로 다른 보스가 등장하며, 약점을 공격하면 추가 점수를 얻을 수 있습니다. 플레이 결과는 웹사이트에 저장되어 랭킹과 개인 기록으로 이어집니다.

## 주요 기능

- 4개 스테이지의 보스 전투
- 무기와 약점 공격을 활용한 점수 획득
- 플레이 점수 저장 및 웹 랭킹 조회
- 로그인 후 개인 게임 기록 확인

## 담당 역할

2인 팀 프로젝트에서 웹사이트와 랭킹 기능을 구현하고 게임 개발을 보조했습니다. 팀원은 게임 개발을 담당했습니다.

## 사용 기술

Unity WebGL · Java · Spring MVC · JSP · MySQL · Docker Compose · Caddy
